 🚀 Projeto atual

 🎯 Jogo de Adivinhação

Um simples jogo feito em C onde o usuário tenta adivinhar um número secreto.  
Inclui níveis de dificuldade e contagem de pontos baseada na proximidade dos chutes.

 📚 Objetivo

Aprender os conceitos fundamentais da linguagem C, como:

- Variáveis e tipos
- Condicionais (`if`, `else`)
- Estruturas de repetição (`while`, `for`)
- Funções
- `switch case`
- Entrada e saída de dados
- Uso da biblioteca padrão (`stdio.h`, `stdlib.h`, `time.h`, etc)
